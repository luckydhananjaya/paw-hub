# Paw Note

Paw Note adalah aplikasi catatan lucu bertema hewan yang bisa digunakan secara offline, tanpa akun.

Seluruh UI dan logika aplikasi berada di `index.html`.

Setiap commit ke branch utama otomatis memicu build APK melalui GitHub Actions (biasanya sekitar 5–8 menit). Unduh `PawNote.apk` dari entri terbaru di tab [Releases](https://github.com/luckydhananjaya/paw-hub/releases).
