# Paw Hub — Personal Notes

Offline-first Android app. No login, ads, cloud, or internet permission.

## Implemented source
- Create, edit, delete, pin and search plain-text notes
- Room local database and Material 3 dark UI
- Save via Back / Save
- GitHub Actions debug APK workflow

## Build
JDK 17, Android SDK 35 and Gradle required. Run `gradle :app:assembleDebug` or trigger the Android Debug APK GitHub Actions workflow.
